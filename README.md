# ✈️ AI Trip Decision Optimizer

> An AI-powered travel decision and trip optimization platform built with Python, Streamlit, MySQL and Machine Learning.

## 📌 Overview

AI Trip Decision Optimizer helps users find the best trip based on their:

- 💰 Budget
- 🌦️ Weather preferences
- 🏨 Hotel preferences
- 🍴 Food preferences
- 🎯 Activities
- 🚆 Transportation
- ⭐ Ratings
- ❤️ Personal interests
- 🗓️ Trip duration

Instead of simply showing travel options, the system **compares and optimizes them** to find the best-value trip for the user.
